# Simple BMI Calculator

This is a basic Python script that I built to practice functions and user inputs. It calculates the Body Mass Index (BMI) using weight and height, then tells the user their weight category.

## How it works:
1. It asks the user for height in meters and weight in kilograms.
2. It calculates the BMI using the formula.
3. It uses if/elif/else statements to print the result (Underweight, Normal, Overweight, or Fat).

## What I practiced in this project:
- Using `input()` and converting data types (`int` and `float`).
- Creating and calling a `def` function.
- Using conditional logic (`if`, `elif`, `else`).
